# Problem Statement (official)
E.D.I.T.H. - Enhanced Digital Identity, Trust & Heuristics. Domain: Cybersecurity, Digital Identity and Privacy.
Users grant apps access to data/files/accounts but lack visibility afterwards. Apps may over-access, request permissions unexpectedly, access too often, attempt restricted resources, or show suspicious patterns. Install-time permissions don't continuously evaluate behaviour.
Build a smart permission management system that monitors data use, detects suspicious activity, and helps users control permissions.
## Seven mandatory features (non-negotiable)
1 Centralized permission management 2 Access monitoring (who/what/when/why) 3 Trust score 4 Suspicious activity detection 5 Permission recommendations 6 Access control (approve/restrict/suspend/revoke) 7 Activity history (events, alerts, permission changes).
Expected: working prototype simulating multiple apps accessing user data, monitoring, detecting, recommending; shows CONTINUOUS trust evaluation. Mandatory features implemented and tested before advanced features.
Positioning: Adaptive Application Trust and Runtime Security Platform, inspired by CIEM / RASP / CNAPP - selected capabilities only; no claims of OS interception, cloud scanning or ML.
